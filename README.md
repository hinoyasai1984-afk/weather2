# 日本主要都市 気象データダッシュボード

[Open-Meteo](https://open-meteo.com/) の公開APIを使い、日本の主要都市の平均気温・降水量の推移を比較できるダッシュボードです。プレーンHTML/CSS/JavaScript製で、ビルド不要・GitHub Pagesでそのまま公開できます。

## 機能

- 都市の選択（東京・大阪・札幌・名古屋・福岡・那覇）
- 期間の切り替え（過去7日間 / 30日間 / 90日間）
- 平均気温・降水量の推移グラフ
- ライト / ダークモード切り替え
- 表形式でのデータ確認

## ローカルで確認する

ブラウザから直接 `index.html` を開くか、簡易サーバーを立てて確認してください。

```bash
python -m http.server 8000
```

`http://localhost:8000` にアクセスします。
